📖 Guide and Useful Information

This portal automatically sends the correct software to your control board. Here's how the three available options work:

1. Restore default firmware

The original factory firmware will be installed. Note: by running this option, any customizations made on the board will be reset to their initial state.

2. Code portion only with SD autorun added

Updates only the internal functions by enabling automatic file reading from the SD card at startup. All your custom settings remain saved (Wi-Fi password, motor step calibration, and custom macro buttons are not touched).

3. Default code portion only without SD autorun

Installs the standard program by removing the automatic SD card check at startup. The machine turns on normally. Even in this case, your user settings, password, and calibrations remain perfectly intact.

🛠️ How to proceed with the installation:

  1. Connect the MKS-DLC32 board to the computer using a common USB cable.
  2. Click the green button "Start Cloud Download and Update" above.
  3. Your browser (Chrome or Edge) will open a small window: select the connection port of your machine (e.g. COM3 or Serial Device) and press Connect.
  4. Wait for the procedure to reach 100% and then turn the board off and back on.
ℹ️ Security requirements: This secure system works directly from the browser, but it strictly requires that you are browsing this website in HTTPS mode.
