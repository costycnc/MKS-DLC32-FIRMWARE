📖 Guide and Useful Information

This portal sends the correct software to your control board completely automatically. Here is how the four available options work:

1. Restore default firmware for NEMA motors

Installs the original factory firmware for machines with NEMA 17 motors. Note: any custom modifications on the board will be reset to their initial state.

2. Restore default firmware for 28BYJ-48 motors

Installs the original factory firmware for machines with 28BYJ-48 geared motors. Note: any custom modifications on the board will be reset to their initial state.

3. Application code only with SD autorun

Updates only the internal functions and enables automatic file loading from the SD card at startup. All your personal settings remain saved (Wi-Fi password, motor step calibration, and custom macro buttons are not touched).

4. Default application code without SD autorun

Installs the standard program, removing the automatic SD card check at startup. The machine boots normally. Even in this case, your user settings, password, and calibrations remain completely intact.

🛠️ How to install:

  1. Connect the MKS-DLC32 board to your computer using a standard USB cable.
  2. Click the green button "Start Cloud Download and Update" above.
  3. Your browser (Chrome or Edge) will open a dialog: select your machine's connection port (e.g. COM3 or Serial Device) and click Connect.
  4. Wait until the process reaches 100%, then power-cycle the board (turn it off and on again).
ℹ️ Security requirements: This secure system runs directly from your browser, but it strictly requires that you are browsing this website over a secure HTTPS connection.
