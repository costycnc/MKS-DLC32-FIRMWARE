## 🧩 Technical Notes

- **Board:** MKS-DLC32 (ESP32-based)
- **Flash mode:** `dout`
- **Flash frequency:** `80 MHz`
- **Flash size:** preserved (`keep`)
- **Baud rate:** `921600`
- **Bootloader address:** `0x1000` (full firmware) / `0x10000` (application only)
